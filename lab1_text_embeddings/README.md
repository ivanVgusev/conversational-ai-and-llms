# Лабораторная работа 1. Текстовые эмбеддинги BERT

В работе сравниваются два способа получить один вектор текста из токенных представлений BERT:

- mean pooling, то есть среднее по токенам без учёта padding;
- CLS pooling, то есть вектор первого токена `[CLS]`.

Для эксперимента используется датасет `ag_news` с четырьмя классами. Модель `bert-base-multilingual-cased` не обучается и применяется только для получения эмбеддингов. Поверх эмбеддингов обучается Logistic Regression.

## Запуск

Для всех лабораторных используется одно окружение в корне репозитория. Рекомендуется Python 3.10, 3.11 или 3.12. Такой вариант подходит для macOS 12 и современных выпусков Ubuntu.

```bash
cd conv_ai_llms
uv sync
uv run jupyter lab lab1_text_embeddings/lab1.ipynb
```

`uv sync` создаст один `.venv` в корне и установит версии из `uv.lock`. Это окружение можно использовать для следующих лабораторных. Если подходящего Python нет, `uv` сможет установить его автоматически.

При первом запуске будут загружены датасет и веса BERT. Для этого нужен интернет. Дальше файлы берутся из локального кэша Hugging Face.

Ноутбук сам обновляет `results/metrics.csv`. В репозитории сохранён результат последнего полного запуска эксперимента.

## Что сравнивается

Mean pooling использует информацию всех настоящих токенов текста. Padding-токены в среднем не участвуют.

CLS pooling берёт представление первого специального токена. У обычного предобученного BERT этот вектор не обязан быть лучшим эмбеддингом предложения, поэтому его качество проверяется экспериментально.

Метрики:

- accuracy;
- macro F1, где каждый класс имеет одинаковый вес.

## Результаты

| Метод | Accuracy | Macro F1 |
| --- | ---: | ---: |
| Mean pooling | 0.8425 | 0.8429 |
| CLS pooling | 0.8175 | 0.8182 |

На выбранной тестовой выборке mean pooling оказался лучше. Разница по macro F1 составила 0.0247. Этот вывод относится к модели `bert-base-multilingual-cased` и использованной выборке `ag_news`.

## Короткие ответы для защиты

### Почему BERT выдаёт не один вектор?

BERT возвращает отдельное представление каждого токена. После этого нужно собрать токенные представления в один вектор текста.

### Чем отличаются mean и CLS?

Mean pooling усредняет представления всех токенов. CLS pooling использует только специальный токен `[CLS]`.

### Почему BERT не обучается?

Цель работы состоит в сравнении способов агрегации готовых представлений. Дообучение BERT добавило бы ещё один фактор и потребовало бы больше вычислений.

### Почему используется macro F1?

Macro F1 сначала считается отдельно для каждого класса, затем результаты усредняются. Поэтому каждый класс одинаково влияет на итоговую метрику.
